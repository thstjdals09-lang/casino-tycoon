# 카지노 타이쿤 (Casino Tycoon)

테이블 하나짜리 작은 홀덤 매장에서 시작해 국내 최고의 카지노로 성장시키는 도트 스타일 방치형(idle) 모바일 게임.

## 핵심 루프

- 테이블은 시간이 지나면 자동으로 매출을 발생시킨다 (방치형).
- **딜러 가챠**로 딜러를 뽑아(N/R/SR/SSR 등급) 테이블에 배정하면 매출이 크게 오른다. 등급이 높을수록 배정 효과와 보유만 해도 적용되는 전체 수익 보너스가 커진다.
- 번 돈으로 **테이블을 강화**하거나 **새 테이블을 구매**해서 매장을 키운다.
- 매출이 일정 기준을 넘으면 **매장을 확장**(프레스티지)해서 다음 등급의 더 큰 매장으로 이동한다 — 자리는 초기화되지만 영구 매출 배율을 얻는다.
- 매장 등급: 구석 테이블 하나 → 동네 홀덤 매장 → 지역 카지노 → 국내 최고 카지노.
- **전직**: 등급 1(동네 홀덤 매장)에서 1차 전직, 등급 2(지역 카지노)에서 1차 선택에 따라 갈리는 2차 전직을 선택한다. 전직 효과(수익/딜러 효율/탭 보너스/오프라인 수익/가챠 확률 보너스)는 영구 적용된다.

## 기술 스택

- [Phaser 3](https://phaser.io/) + TypeScript + Vite — 도트 그래픽 캔버스 렌더링
- HTML/CSS 오버레이 HUD (상점/딜러 관리 패널)
- `localStorage` 기반 저장 + 오프라인 수익 계산 (최대 8시간)
- 모바일 배포는 [Capacitor](https://capacitorjs.com/)로 감쌀 예정 (아직 미적용)

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm run build     # 프로덕션 빌드
```

## 프로젝트 구조

```
src/
  game/       상태/밸런스 로직 (Phaser 비의존적, 순수 TS)
    types.ts        데이터 모델
    balance.ts       매장 등급별 성장 곡선 설정
    GameState.ts      상태 + 액션(구매/강화/고용/배정/확장) + 틱
    SaveManager.ts    localStorage 저장/불러오기
    events.ts         Scene ↔ HUD 간 상태 변경 알림용 이벤트 버스
  scenes/
    MainScene.ts      매장 바닥 렌더링, 테이블 탭 상호작용
  ui/
    HUD.ts            우측(모바일은 하단) DOM 오버레이 패널
```
